## Building

Either draft compiles with a standard TeX Live installation that
includes `texlive-publishers` (for `elsarticle.cls`). On Debian or
Ubuntu:

```bash
sudo apt-get install texlive-latex-recommended texlive-latex-extra \
                     texlive-publishers texlive-fonts-recommended

cd docs/paper
pdflatex dirac_wavepacket_softwarex.tex
pdflatex dirac_wavepacket_softwarex.tex       # run twice for cross-references
```

## SoftwareX draft — structure

Follows the official Elsevier OSP LaTeX template, downloaded from
`legacyfileshare.elsevier.com/promis_misc/softwarex-osp-template.tex`.

| Section                                  | Purpose                                                        |
|------------------------------------------|----------------------------------------------------------------|
| Required metadata / Current code version | Mandatory C1-C8 metadata table.                                |
| 1. Motivation and significance           | Scientific background, related tools, statement of need.       |
| 2. Software description                  | 2.1 architecture, 2.2 functionalities.                         |
| 3. Illustrative examples                 | Example 1 (valley filter) + Example 2 (Klein angular scan).    |
| 4. Impact                                | Research impact, user community, comparison with neighbours.   |
| 5. Conclusions                           | Short summary.                                                 |
| Acknowledgements, references             |                                                                |
| Current executable software version      | Mandatory S1-S7 metadata table.                                |

Target: 4000 words maximum, 6 figures maximum. Current word count is
about 2000, with 5 figures — comfortably within both limits. The
draft typesets to roughly 6 pages in Elsevier's final two-column
form (10 pages here in single-column preprint mode).

Mandatory requirements the SoftwareX editor will check:

- [x] Five numbered sections in the exact order above.
- [x] `elsarticle-num` citation style (via the default `elsarticle` class).
- [x] Two metadata tables (Code metadata + Executable software metadata).
- [ ] GitHub URL in metadata tables — provisional `github.com/can-yesilyurt/Dirac-Wavepacket`; to be replaced with the real URL before submission.
- [ ] Package rename — draft still uses `dirac_wavepacket` throughout.
- [ ] Public GitHub repository with `README.md` and `LICENSE` present.
- [ ] Two companion-paper citations are placeholders ("submitted" / "in preparation") — replace with arXiv IDs before submission.
